# Architecture Decision Records

This folder contains [MADR](https://adr.github.io/madr/) (Markdown Architectural Decision Records) for the Palladio Slingshot simulator.

## Naming convention

Files follow the pattern `NNNN-title-with-dashes.md`, where `NNNN` is a consecutive four-digit number.

## Index

| ADR | Title | Status |
|-----|-------|--------|
| [0001](0001-simulation-snapshot-and-initialization.md) | Simulation snapshot and initialization via event-driven extension contracts | accepted |

Functional requirements referenced by these decisions are documented in [../requirements/](../requirements/).
